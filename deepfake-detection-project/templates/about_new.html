About This Project

Project Overview

This is an advanced deepfake detection system built using state-of-the-art deep learning techniques to identify AI-generated or manipulated facial images.

Model Architecture

Model 4: Attention → EfficientNet → SE (Squeeze-and-Excitation)

  • Stage 1: Enhanced CBAM (Convolutional Block Attention Module)
  • Stage 2: EfficientNetB0 backbone pre-trained on ImageNet
  • Stage 3: Enhanced SE (Squeeze-and-Excitation) blocks
  • Stage 4: Multi-layer classifier with regularization
