About This Project

Project Overview

This is an advanced deepfake detection system built using state-of-the-art deep learning techniques to identify AI-generated or manipulated facial images.

Model Architecture

Model 4: Attention → EfficientNet → SE (Squeeze-and-Excitation)

  • Stage 1: Enhanced CBAM (Convolutional Block Attention Module) for initial feature extraction
  • Stage 2: EfficientNetB0 backbone pre-trained on ImageNet with fine-tuning
  • Stage 3: Enhanced SE (Squeeze-and-Excitation) blocks for channel-wise attention
  • Stage 4: Multi-layer classifier with regularization and dropout

Training Details

Dataset
  • WildDeepfake Dataset (Kaggle)
  • Contains real and AI-generated faces
  • 75/25 train-validation split
Training Configuration
  • Optimizer: Adam
  • Loss: Binary Cross-Entropy
  • Batch Size: 16
  • Image Size: 224x224
  • Data Augmentation: Rotation, Shift, Zoom, Brightness
